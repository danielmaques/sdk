# Pushify Android SDK

Original Android client for Pushify. This package uses Google Play's Billing Library and Pushify's server protocol; it does not contain source from another purchase SDK.

The current preview includes the typed acquisition-link resolver and Android Play Install Referrer token reader. Full customer, product, purchase, restore, receipt-sync, and entitlement APIs are still under development. Do not use this preview for production purchases.

The public artifact coordinates and release workflow will be finalized before the first Maven release.
