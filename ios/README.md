# Pushify iOS SDK

Original Swift client for Pushify, built around Apple's StoreKit APIs and Pushify's server protocol. No source from another purchase SDK is included.

The current preview includes the typed acquisition-link resolver and a user-initiated deferred-token pasteboard reader. Full customer, product, StoreKit purchase, restore, transaction-sync, and entitlement APIs are still under development. Do not use this preview for production purchases.

The public package and release workflow will be finalized before the first Swift Package release.
